One sentence explaining the modern internet to a traveler from 1800, using only words from his own century.

> "It is one great post office with no walls, where any letter finds any door before the ink dries, and every book ever written waits to be read."

Run it:

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt`.
